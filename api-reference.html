API Reference
Endpoints for content routing, purchase plan optimization, and real-time paid content fetching.
Base URL: https://agent-content-router.onrender.com
Optimize
POST /optimize
Decompose a query into sub-queries, search free sources, score coverage, and identify gaps where paid content is needed. Returns a job_id immediately — poll GET /job/<job_id> for the result (typically 30–90s).
⚡ Async: this endpoint starts a background job. Use /job/<job_id> to retrieve the result.
query *
customer_id
Response
Run the request to see the response.
GET /job/<job_id>
Poll for the result of a background optimize job. Returns status: "running" with elapsed seconds while in progress, status: "done" with the full result payload, or status: "error" with an error message. Jobs expire after 10 minutes.

Paid content
POST /fetch-exa
On-demand fetch of paid content via Exa for a specific sub-query. Call this after /optimize identifies a gap and you decide the content is worth buying. Returns results with coverage_score already computed, plus estimated cost.
